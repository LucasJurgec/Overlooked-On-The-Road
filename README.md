Overlooked on the Road

A data visualisation project exploring motorcyclists as an overlooked road safety concern, built using D3.js. Created as a team project (2 members) for coursework at Swinburne University of Technology.

Live Demo

🔗 View the live site <!-- https://lucasjurgec.github.io/Overlooked-On-The-Road/ -->

About

Motorcyclists are disproportionately represented in road trauma statistics relative to their share of registered vehicles on Australian roads. This project visualises hospitalisation and vehicle registration data to highlight that gap.

Visualisations
Choropleth map — geographic distribution of motorcycle-related hospitalisations
Dumbbell chart — comparison across categories/regions
Line chart — trend over time
Donut Chart — percentage of registered motorcycles compared to percentage of motorcycle hospitalisations
Data & Methodology

Data, including registered vehicle datasets, was sourced and cleaned using KNIME before being visualised with D3.js.
